# My Phone Tool 📱
### Phone Number Lookup & OSINT Tool

A lightweight OSINT tool built on iPhone that validates phone numbers, detects carrier/country, and generates interactive maps. Built in Harare, Zimbabwe 🇿🇼

**Repo:** https://github.com/Lilmunax98/my-phone-tool

## Features
- Location Tracking - City / region from phone prefix
- Carrier Detection - Econet, NetOne, Telecel, etc
- Validation - Real vs fake numbers
- Interactive Maps - Auto-generates HTML maps
- Cross-Platform - iPhone (iSH), Android (Termux), PC

## Installation

1. Clone:
git clone https://github.com/Lilmunax98/my-phone-tool.git
cd my-phone-tool

2. Install:
apk add python3 py3-pip
pip3 install -r requirements.txt

3. Run:
python3 phone_lookup.py
