# My Phone Tool 📱

Repo: https://github.com/Lilmunax98/my-phone-tool

## Quick Start

1. git clone https://github.com/Lilmunax98/my-phone-tool.git
2. cd my-phone-tool
3. apk add python3 py3-pip (iSH) / pkg install python (Termux)
4. pip install -r requirements.txt
5. python3 phone_lookup.py

## Requirements
phonenumbers, folium, pycountry, requests
